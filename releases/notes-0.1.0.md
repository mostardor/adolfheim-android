## ADOFAI Android port 0.1.0

First Android build.

- **Runs on Android:** ARM64, Vulkan / OpenGL ES 3, landscape.
- **Custom levels without Steam Workshop:** levels live in a local folder on the device.
- **Level import:** native Android file picker for `.zip` and `.adofai`, including zips with Korean file names.
- **Download Levels:** level browser for ADOFAI.gg and TUF that downloads and installs on the device.
- **Touch:** drag to scroll the level list, short tap to enter; on-screen pause button.
- **Online:** portal in the main menu and first version of the rooms.
- **Fixed:** simultaneous level events ran in a different order than in the original game, leaving a decoration on screen in some
  levels.

This release has no game files attached.

### Português

Primeira build para Android.

- **Roda no Android:** ARM64, Vulkan / OpenGL ES 3, paisagem.
- **Fases personalizadas sem a Oficina Steam:** as fases ficam numa pasta local do aparelho.
- **Importar fases:** seletor de arquivos do Android para `.zip` e `.adofai`, inclusive zips com nomes em coreano.
- **Baixar Níveis:** navegador do ADOFAI.gg e do TUF, que baixa e instala no aparelho.
- **Toque:** arrastar rola a lista, toque curto entra na fase; botão de pausa na tela.
- **Online:** portal no menu principal e primeira versão das salas.
- **Corrigido:** eventos simultâneos da fase rodavam em ordem diferente da do jogo original e deixavam uma decoração na tela em
  algumas fases.

Esta versão não tem arquivos do jogo anexados.
