## ADOFAI Android port 0.3.0

- **Level queue:** the host can line up up to 8 levels for the room.
- **New level picker:** each level shows its artwork, title, artist and author, with a *Workshop* / *Local* tag,
  search, filters and a level counter.
- **Options screen:** language, main server and fallback server.
- **Room screen in groups:** "Level" and "Modifiers".
- **Fixed:** texts no longer flash in Portuguese for one frame when another language is selected.
- **Fixed:** the level list could come up empty before the level folders had been read.

### Português

- **Fila de fases:** o anfitrião pode enfileirar até 8 fases para a sala.
- **Seletor de fases novo:** cada fase mostra a arte, o título, o artista e o autor, com selo *Oficina* / *Local*,
  busca, filtros e contador.
- **Tela de opções:** idioma, servidor principal e servidor de reserva.
- **Tela da sala em grupos:** "Fase" e "Modificadores".
- **Corrigido:** os textos não piscam mais em português por um quadro quando outro idioma está selecionado.
- **Corrigido:** a lista de fases podia vir vazia antes de as pastas de fases serem lidas.
