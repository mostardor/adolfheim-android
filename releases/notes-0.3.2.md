## ADOFAI Android port 0.3.2

- **One file only:** the OBB is gone. The game content is now inside the APK (about 615 MiB). Install the APK and open it; there is nothing to paste in `Android/obb` anymore.
- **Neo Cosmos DLC content removed:** it is not part of the port and is no longer shipped (about 130 MB less than 0.3.1).
- **Notice for levels that use DLC features:** custom levels that use Neo Cosmos features still play, with those effects disabled, and the game tells you when the level starts.

**Updating from 0.3.1 or older:** install the new APK over the old one (your data is kept) and delete the old `.obb` from `Android/obb/com.adofaiport.personal/` to get about 650 MB back.
You need roughly 1.3 GB free while installing (the APK is copied once during the installation).

## How To Install

- **Install the APK and open it**
- **Open the game and enjoy** (no .obb needed)

### Português

- **Um arquivo só:** o OBB acabou. O conteúdo do jogo agora está dentro do APK (cerca de 615 MiB). Instale o APK e abra; não há mais nada para colar em `Android/obb`.

**Atualizando da 0.3.1 ou anterior:** instale o APK novo por cima do antigo (os dados são mantidos) e apague o `.obb` antigo de `Android/obb/com.adofaiport.personal/` para recuperar cerca de 650 MB.
Você precisa de cerca de 1,3 GB livres durante a instalação (o APK é copiado uma vez no processo).

## Como Instalar

- **Abra o jogo e divirta-se** (não precisa de .obb)
