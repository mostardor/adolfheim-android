## ADOFAI Android port 0.3.1

- **Room password (optional):** set when creating a room, typed when joining a locked room; rooms with a password are marked in the list.
- **Host tools:** the host can now **Ban** a player (by IP, while the room exists), besides *Remove*.
- **Report:** a button next to other players' names; the room server logs it and the host is notified.
- **Chat:** limit on how fast messages can be sent (anti-spam) and an optional swear-word filter for the chat and player names (Options screen, on by default).
- **Fixed:** the level list could come up empty after coming back from a match.
- **Fixed:** a level download that receives no data for 30 s now fails with a message instead of staying at "Downloading 0%".
- **Fixed:** touches on the online screens went through to the level selector behind them, which could enter a level by itself.

**Updating from 0.3.0:** install the new APK **and replace the `.obb`** (it changed). Room password, ban and report need the updated room servers, which are already running.

### Português

- **Senha de sala (opcional):** definida ao criar a sala e digitada ao entrar numa sala com senha; salas com senha aparecem marcadas na lista.
- **Ferramentas do anfitrião:** agora o anfitrião pode **Banir** um jogador (por IP, enquanto a sala existir), além de *Remover*.
- **Denunciar:** um botão ao lado do nome dos outros jogadores; o servidor da sala registra e avisa o anfitrião.
- **Chat:** limite de velocidade das mensagens (anti-spam) e filtro de palavrões opcional para o chat e os nomes (tela de Opções, ligado por padrão).
- **Corrigido:** a lista de fases podia vir vazia depois de voltar de uma partida.
- **Corrigido:** um download de fase que fica 30 s sem receber dados agora falha com mensagem, em vez de ficar em "Baixando 0%".
- **Corrigido:** os toques nas telas do online atravessavam até o seletor de fases de trás, o que podia entrar numa fase sozinho.

**Atualizando da 0.3.0:** instale o APK novo **e troque o `.obb`** (ele mudou). Senha, banimento e denúncia dependem dos servidores de sala atualizados, que já estão no ar.
